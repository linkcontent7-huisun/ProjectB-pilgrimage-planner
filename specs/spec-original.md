# [Project B] 초개인화 여행 계획 수립 AI 에이전트

- 분야: AI 응용 학습 · 구분: Term Project · 학습시간: 80시간 (팀)
- 과제 코드: 확인 필요 (플랫폼 학습맵 기준으로 갱신)

## 1. 미션 소개

예산, 날씨, 이동 동선, 취향까지 복합적인 조건을 LLM 혼자 처리하면 할루시네이션이 생긴다.
에이전트가 지도 API와 검색 도구를 직접 호출해서 실시간 정보를 확인하는 구조가 그 문제를 줄인다.
최적 여행 경로를 지도 위 동선과 타임라인으로 시각화하는 AI 에이전트를 팀으로 구축한다.

사용자의 예산, 날씨, 이동 동선 등 복합적인 제약 조건을 스스로 분석하고 추론하여 최적의 여행 경로를
제안하는 AI 에이전트를 개발한다. 에이전트가 지도 API와 검색 도구를 직접 호출해 실시간 정보를
반영함으로써 할루시네이션을 최소화한 구체적이고 실행 가능한 계획을 수립한다. 사용자와의 대화를 통해
여행 조건을 정교하게 수집하고, 최종 결과물은 지도 위 동선과 타임라인으로 시각화하여 웹 서비스로
제공한다. 에이전트가 장소를 선정하고 경로를 최적화한 논리적 근거를 확인할 수 있는 추론 로그 화면까지
구현한다.

## 2. 최종 결과물

- **여행 계획 입력 및 시각화** — 여행지, 날짜, 인원, 예산, 선호 스타일 입력 → 일별 동선과 장소 정보가 지도와 타임라인에 시각화
- **의사결정 로그 UI** — 에이전트가 도구를 사용하여 정보를 검색하고 경로를 최적화하는 과정이 실시간으로 표시
- **JSON 스키마 정의** — 프론트엔드와 AI 모델 간 데이터 교환을 보장하는 여행 일정 JSON 스키마

## 3. 과제 목표

- 복합 요구사항을 하위 작업으로 분해하고 순차 수행하는 Reasoning 과정 설계
- LLM이 외부 지도 API와 검색 엔진을 적절한 시점에 스스로 호출하도록 Function Calling 구현
- 비정형 자연어 출력을 지도 UI 렌더링에 적합한 정형 JSON으로 변환하고 구조 검증
- LangChain 또는 LangGraph로 에이전트 상태 관리와 흐름 제어

## 4. 기능 요구 사항 (전부 충족)

| # | 항목 | 내용 |
|---|---|---|
| 1 | 여행 정보 입력 | 목적지, 기간(N박 M일), 인원, 예산, 선호 테마 입력 인터페이스 |
| 2 | 지도 API 연동 | OpenAI API(또는 동급 LLM) Function Calling으로 Google Maps / Naver Map / Kakao Map 중 하나를 호출해 좌표 획득 |
| 3 | 실시간 검색 | Tavily, SerpApi 등 검색 도구로 실시간 정보 검색 |
| 4 | 진행 상태 표시 | '날씨 검색 중', '경로 계산 중' 등 현재 수행 중인 작업을 UI에 표시 |
| 5 | 타임라인 시각화 | 날짜별·시간대별 타임라인 컴포넌트 렌더링 |
| 6 | 지도 시각화 | 각 장소를 마커로 표시, 마커 간 이동 순서를 시각적으로 연결 |
| 7 | JSON 스키마 검증 | LLM JSON 응답이 스키마와 불일치하면 재생성 또는 예외 처리 |
| 8 | 일정 수정 기능 | 특정 장소 삭제·변경 요청 시 전체 동선 재계산 |
| 9 | 에이전트 프레임워크 | LangChain 또는 LangGraph 필수 |
| 10 | API 키 관리 | 코드에 노출하지 않고 `.env` 등 환경 변수로 관리 |

## 5. 보너스 과제

- **페르소나 기반 계획 생성** — 맛집 탐방러, 힐링 여행객, 짠내 투어 등 페르소나별로 다른 스타일의 계획
- **PDF 다운로드 및 이메일 발송** — 일정을 PDF로 다운로드하거나 이메일로 발송

## 6. 개발 환경

- Python 3.10 이상
- LangChain 또는 LangGraph 필수
- LLM: OpenAI GPT-4o 또는 동급
- 지도 API: Google Maps / Naver Maps / Kakao Maps 중 하나 필수
- 검색 API: Tavily, SerpApi 등

## 7. 제약 사항

- **반드시 지도 UI 포함.** 텍스트 리스트만 출력하는 것은 인정하지 않는다.
- API 키는 환경 변수로 관리한다.

## 8. 결과 예시 (참고용, 정답 아님)

화면: 좌측 타임라인 패널 / 우측 지도 패널

```
1일차 (2024-05-01)
- 10:00 | 제주국제공항 도착
- 11:30 | 자매국수 (점심 식사) - 고기국수 맛집
- 13:00 | 용두암 (관광) - 해안 도로 드라이브 코스 포함
```

지도: 1, 2, 3 번호 마커 + 마커 사이를 잇는 파란색 경로 선

에이전트 로그:

```
[Thinking] 점심 식사 장소 선정 중...
[Tool Call] search_restaurant(keyword='제주 공항 근처 맛집', category='국수')
[Tool Output] 자매국수, 올래국수 정보 반환
[Decision] 동선을 고려하여 '자매국수' 선정
```

LLM 응답 JSON 구조:

```json
{
  "plan_name": "제주 힐링 여행",
  "days": [
    {
      "day": 1,
      "date": "20XX-05-01",
      "places": [
        {
          "name": "자매국수",
          "type": "restaurant",
          "coordinates": {"lat": 33.50, "lng": 126.52},
          "description": "고기국수가 유명한 맛집"
        }
      ]
    }
  ]
}
```
