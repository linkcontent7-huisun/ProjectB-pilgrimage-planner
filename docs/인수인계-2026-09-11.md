## API 키 현황과 다음 행동

### 네이버 지도: NCP 가입 완료, Maps 애플리케이션 등록은 아직

사용자는 NAVER Cloud Platform 가입을 완료했다. 다음은 NCP 콘솔에서 지도 API용 Application을 등록하는 단계다.

1. 콘솔에서 `AI·NAVER API → Maps → Application`으로 이동한다.
2. Application을 등록하고 다음 서비스를 선택한다.
   - Web Dynamic Map
   - Geocoding
   - Directions 5
3. Web 서비스 URL에 개발용 `http://localhost:8000`을 등록한다.
4. 배포 후에는 실제 배포 주소(예: Vercel URL)도 추가한다.
5. 발급된 Client ID와 Client Secret을 저장소의 `.env`에 아래 항목으로만 입력한다.

```dotenv
NAVER_MAP_CLIENT_ID=
NAVER_MAP_CLIENT_SECRET=
```

키 값은 채팅, 문서, 코드, Git 커밋에 남기지 않는다. `.env`는 이미 Git 추적 대상에서 제외되어야 한다.

### 중요한 구분: NCP Maps와 NAVER Developers Local Search

현재 **Project B에는 NCP Maps가 맞다**. 지도 표시·지오코딩·경로 탐색을 위해 사용한다.

별도 과제인 `assignments/A1-2-travel-planner`는 맛집 장소 검색에 **NAVER Developers의 Local Search API**를 사용할 수 있다. 이 API의 Client ID/Secret은 NCP가 아니라 <https://developers.naver.com/>에서 `검색(Search)` API를 선택해 발급한다. 두 종류의 키와 발급 경로를 혼동하지 않는다.

### Tavily

<https://tavily.com>에서 키를 발급하여 `.env`의 다음 항목에만 저장한다.

```dotenv
TAVILY_API_KEY=
```

## 실행 방법

저장소 루트에서 실행한다.

```powershell
py -3.13 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
python -m pytest -q
```

API 키 입력 뒤 개발 서버는 이후 Task에서 `uvicorn main:app --reload`로 실행할 예정이다.
